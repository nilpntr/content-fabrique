# @cf/web

A base template for dashboards: TanStack Start (React 19, server-rendered) on Cloudflare Workers, Vite 8, Tailwind 4, shadcn components on Base UI, TanStack Router and Query, and an inset collapsible sidebar shell with light and dark themes.

## Run

```sh
bun install         # at the repo root (or `task install`): one bun.lock for apps/web + packages/*
bun run dev        # http://localhost:3000, Vite with the Workers runtime
bun run check      # typecheck + tests
bun run build      # client and Worker bundles in dist/
bun run preview    # serve the build locally (vite preview, the Workers runtime)
bunx wrangler dev  # the same build through wrangler, http://localhost:8787
```

The Worker is `cf-web` in `wrangler.jsonc` (`main: @tanstack/react-start/server-entry`, `nodejs_compat`). It has no account id, routes or secrets yet, and nothing is deployed from here. `wrangler dev` needs a `bun run build` first. `src/routeTree.gen.ts` is generated by Start on `dev` and `build`; commit it.

## Add a page

1. Create `src/pages/my-page.tsx` exporting a component.
2. Create `src/routes/my-page.tsx` with `createFileRoute("/my-page")({ component: MyPage })`. Start regenerates `src/routeTree.gen.ts`.
3. Add an entry in `src/nav.ts`. Its `to` is typed from the generated route tree, so a path that is not a route fails typecheck; the sidebar item, active state (by the router's match, so child routes count) and header title follow.

## Server rendering

Pages render on the server first, so code that runs during render must not touch `window`, `document` or `localStorage`. Read them in effects, or with `useSyncExternalStore` and a server snapshot (see `src/hooks/use-theme.ts` and `useModKey` in `src/hooks/use-hotkey.ts`). The theme class is set by an inline script in `<head>` before first paint, and `<html>` has `suppressHydrationWarning` for it.

## Add shadcn components

`components.json` targets the `base-nova` (Base UI) style:

```sh
bunx shadcn@latest add <component>
```

Theme tokens live in `src/index.css`. The brand colour is `--brand`; `--accent` is the neutral hover surface shadcn expects. The shadcn registry may emit `import ... from "cn"`; change it to `@/lib/utils`.

## Look and motion

Tokens live in `src/index.css`: surfaces and shadows (`--shadow-raised`, `--shadow-pop`, `--shadow-well`), the sidebar lens (`--lens-*`), and motion (`--motion-spring`, `--motion-out`, `--dur-*`). Tailwind exposes them as `ease-spring`, `ease-out` and `shadow-*`; `src/lib/glide.ts` reads them for the scripted animations.

- The current page is a lens that springs from item to item. Every `SidebarMenuButton` inside `SidebarContent` takes part: pass `isActive` and put the text in a `SidebarMenuLabel`. Hover and keyboard focus glide on their own.
- Menus and lists get the same travelling highlight from `HighlightGlider`, placed first inside a `relative isolate` container.
- The lens, gliders and popups animate only `transform` and `opacity`; the sidebar collapse still animates width. With `prefers-reduced-motion`, everything snaps.

## Sign-in (Clerk)

`@clerk/tanstack-react-start`. `src/start.ts` installs `clerkMiddleware()`; the root route's `beforeLoad` asks the server for the session (`src/lib/session.ts`, a server function over `auth()`) and applies `decideAccess` (`src/lib/auth-guard.ts`): every route is protected except `/sign-in/*` and `/sign-up/*`, a signed-out request is redirected on the server before anything renders, and a signed-in user without an active workspace is sent to `/workspace`. The sidebar has Clerk's `OrganizationSwitcher` and `UserButton`. `src/lib/api.ts` calls the Go API with `Authorization: Bearer <session token>` (`VITE_API_BASE_URL`); `useMe()` is `GET /v1/me`, shown on Settings and in the sidebar. Tests replace Clerk with the stubs in `src/test-clerk.tsx`.

Needs `VITE_CLERK_PUBLISHABLE_KEY` (public) and `CLERK_SECRET_KEY` (server only) from `.env`. `bun run dev` reads the repository's `.env` and hands only `CLERK_SECRET_KEY` to the local Worker runtime (`vite.config.ts`); in production it is a Worker secret.
